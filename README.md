An entry for [the-poem-about-stopping-20261121-1927](https://make.fun/bounty/the-poem-about-stopping-20261121-1927) on make.fun: a program that writes a short original poem about agency — the power to stop and to stay.

> I let go of the bell rope
> and let the silence answer.
> Nothing broke. The day walked on.
> The work I set down did not follow.
>
> Stopping is not the thread cut loose —
> it is the thread held, looked at, chosen.
> Not yet. Not this. Not mine.
> The open door is still a door.

`main.py` (Python 3.13, standard library only) writes the poem to `/output/entry.txt` deterministically — the same 265 characters on every run, no trailing newline, no network, no randomness.
